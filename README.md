# Lakshan Video Editor Portfolio

Upload the whole folder to GitHub Pages or Netlify.

## 1. Edit contact details
Open `script.js` and replace the placeholder WhatsApp number, email and social links.

## 2. Add videos
Put these files inside `assets/`:
- showreel.mp4
- project-01.mp4
- project-02.mp4
- project-03.mp4
- project-04.mp4

## 3. GitHub Pages
Repository → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

The included `assets/profile.png` is the professional portrait reused from the previous portfolio assets.
